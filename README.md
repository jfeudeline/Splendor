# Splendor

A Rust implementation of the board game Splendor, playable against AI players — and the
first step towards a small board game platform for web and mobile.

This is a personal learning project.

- [Roadmap](docs/ROADMAP.md)
- [Architecture Decision Records](docs/adr/README.md)

> Splendor is a game by Marc André, published by Space Cowboys. This project is not
> affiliated with the publisher; game rules and card data belong to their owners.
