# Project instructions

## Session tracking

- At the start of a work session, read `docs/PLANNING.md` and identify the next unchecked step.
- At the end of each work session, ask the user for:
  - total duration;
  - start and end commit;
  - completed step;
  - blockers or detours;
  - the next step.
- Update `docs/PLANNING.md`: session log, step status, actual sessions, and projection.
- Never invent a duration. If the user does not provide it, write `à renseigner`.
- Remind the user that they asked to report their work time at the end of every session.
